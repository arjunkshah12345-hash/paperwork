## Design Context

### Users
People who need a free, open-source alternative for everyday PDF tasks, without accounts or document uploads.

### Brand Personality
Clean, calm, practical. Keep the interface focused on completing a task rather than marketing.

### Aesthetic Direction
The user explicitly requested a cleaner UI. Use warm neutral surfaces, readable sans-serif type, restrained terracotta accents, and generous spacing. Support light and dark themes and mobile screens.

### Design Principles
- Show each tool once; avoid competing navigation and repeated promotional sections.
- Prioritize file selection, tool discovery, and clear processing controls.
- Use consistent typography and spacing instead of decorative illustrations.
- Preserve all operations, keyboard access, and visible focus states.
