# Storylines — Paperwork launch

1. **One table's trip (picked).** Result-first, object-to-object chain. A real quarterly-report table is stuck in a PDF; pasting it gives one column of text that sums to 0; Paperwork turns the same table into a real spreadsheet whose cells sum to $4,150,550.00, processed on your device. Every beat uses the real sample file and the real output.
2. **Seventy-five doors.** Type carries the argument: the tool grid as a wall of doors, cut on the beat, each door opening on one real conversion. Bolder, but closer to a feature list.
3. **The upload that never happens.** Life before/after: a progress bar sending a private contract to "a server somewhere" stalls; the same file is processed in place with the network panel showing zero requests. Strong privacy story, weaker visual payoff.
